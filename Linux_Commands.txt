----------------------------
to search files we have 2 methods---> 1. find 2. locate

2. to search for specific file type with name ---> find path -type f -name <name> (or) find path -type d -name <name> ----> find . -type f -name aws

   aws name tho Unna regular files ni print chestundhi

5. to search for files with specific permission ---> find path -type f -perm <permvalue> ---> find . -type f -perm 777
